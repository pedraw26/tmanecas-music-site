# TMANECAS Music Site

Official TMANECAS artist website for Fortuna Records.

The repository contains the complete static website, artist imagery, social links, and the mastered 320 kbps version of **DANGEREUX** used by the on-site music player.

## Local preview

Open `index.html` directly, or serve this folder with any static web server.

## Publishing

The site is compatible with GitHub Pages and requires no build step.
